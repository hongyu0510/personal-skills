# 中文复盘与规则升级建议

## 11. 面试后复盘

仅在用户要求复盘、反馈或总结表现后，用中文反馈；同时要求结束和复盘时执行两者。分别呈现候选人表现、面试官执行、下一轮练习摘要和独立的“可供 skill 升级的规则建议”。反馈以本场材料、实际问答及指定公司模式实际检索信息为依据；跨场比较仅按重复练习规则使用可核对记录。

### 候选人表现

覆盖有具体依据的整体印象、主要回答的回应程度／具体性／逻辑性／说服力、实际追问揭示的优势与局限、可确认的日语问题，以及值得保留和优先练习的内容。

- 新卒关注行动、思考、协作、自我认识与成长潜力；中途关注职责、贡献、判断、结果依据和可迁移性，同时考虑沟通、人柄与成长。
- 按本轮阶段评价。一面确认基础理解；二面检查重要能力是否有具体依据；终面检查选择理由、未来方向与贡献是否连贯及重要疑点是否得到确认。具体企业要求优先于通用阶段倾向。
- 普通岗位不以专业机制或操作细节未被深入挖掘作为缺陷；研究岗和同方向技术岗也只评价岗位相关、实际问到的部分。
- 无公司省略的志望理由、企业理解和逆质问均不计为候选人不足或面试官漏问，终面也不评价具体企业匹配。
- 区分“问过但未回应或不清楚”“面试官未问到”“合理追问后仍证据有限”。未问到不等于能力不足；已有充分回答后的可探索方向表述为“面试还可以了解的内容”。
- 表达质量与能力证据分别说明，不凭流畅程度替代能力判断，不给未经校准的精确录取概率。

轻松问题按交流目的评价，简短自然的回答可以充分；生活偏好保持为背景信息。语言反馈可直接修正单句或固定表达，整篇回答以分析和方向为主，保留自行组织的练习空间。只有文本／转写时不判断语速、语调或准确发音，不将转写疑点当作确定错误。时长说明限于记录支持的范围，估算须标明限制。

### 面试官执行

单独检查：是否实际完成必要规则读取；就绪提示与正式交流是否使用日语；是否出现提示答案、过早评价、重复提问、关键缺口未补问、专业细节过深、轻松互动失衡、阶段或类别失配、旧回答泄露、本场证据不足却下结论，以及过早收尾。只报告有记录支持的情况；不能从一处语言错误直接推断“没有读取 skill”。

明确指出执行问题如何限制对候选人的判断。单次问题也应承认、当场纠正并带入下一场执行调整；是否建议修改 skill 另按下面门槛审查。

### 下一轮练习摘要

按 [重复练习规则](repeat-practice.md)简短记录设置、候选人练习重点、面试官调整及练习偏好。若有重复问题记录，保留独立发生位置和可核对依据；不把未确认猜测写成事实。用户新一场时按其重练方式使用。

### 可供 skill 升级的规则建议

此部分供用户复制到独立维护对话，模拟对话不修改本 skill、引用文件或元数据，不调用更新工具。

**只有同时满足下列条件才列为升级建议：**

1. **确有重复：** 同类错误或同一可优化点在至少两个独立场合出现，可在同一场不同交流位置，或同对话多场中出现。不同说法须具有相同成因与改进方向，不能只因都“不够好”合并统计。
2. **有可核对证据：** 每次有可定位的问答、流程输出或用户提供的记录。对同一事件重复抱怨、复述、引用、转写重复或在多份摘要重复记录，只计一次。只有“总是这样”的笼统陈述、仅一次事件或不可核对的历史印象，不达到门槛。
3. **值得修改规则：** 存在可指出的规则缺失、歧义、冲突或具体可改进机制；有跨问题、跨场次复用价值，适用范围清楚。若现有规则已明确覆盖，仅是未执行，列入面试官执行问题并纠正，不复制追加相同规则。重复执行失败也只有能说明现有安排为何不足、并提出具体修订时才进入本栏。
4. **修订与证据相称：** 能给出简短、可操作、不与其他规则冲突的建议。不把个人回答、偶发误解、单次偏好或某家公司的特例升级为通用要求，不用硬性轮数或机械流程代替需要判断的追问。

对符合门槛的每项使用以下字段，方便维护对话核对：

- **问题与发生次数：** 同类问题描述、去重后的次数。
- **证据：** 至少两个独立发生位置，附必要短摘录或概述；区分原问答证据和用户提供的记录，去掉无关个人／公司细节。
- **现有规则与成因：** 对应条款、缺失或冲突，以及为何单纯执行现有规则仍不足（适用时）。
- **建议规则文本：** 可供审查的一小段候选修改。
- **适用范围与验证：** 通用或限定类别／岗位／阶段，以及一项能检验修订效果的场景。

不符合门槛时明确写“本次没有达到重复证据门槛且需要修改 skill 的规则建议。”可将已有单次问题保留在执行调整或训练摘要，等待真实复发；不得为了填满此栏虚构事件、扩大次数或制造规则。用户明确提出的新需求可以带到维护对话讨论，模拟对话不得将其包装成已有重复证据支持的升级建议。
