# Personal Skills

个人 Codex skills 仓库，用于在自己的电脑之间安装、备份和更新可复用规则。

## 日本求职

显示名称：**日本求职**  
调用标识：`$jp-shinsotsu-interview`  
仓库路径：[`skills/jp-shinsotsu-interview`](skills/jp-shinsotsu-interview)

支持新卒／中途的一面、二面、终面；指定公司或无公司练习；同对话完整重练、针对性训练与中文复盘。准备就绪和正式面试使用日语。普通岗位控制专业细节深度。

## 在另一台电脑首次安装

先确保该电脑能够访问这个私有 GitHub 仓库。仅登录同一 Codex 账号不等于已安装本地 skill。

在该电脑的 Codex 中发送：

```text
使用 $skill-installer，从 GitHub 仓库 hongyu0510/personal-skills 的 main 分支安装 skills/jp-shinsotsu-interview，作为我的个人 skill。
这是私有仓库，请使用我已登录的 GitHub 身份访问。
```

安装完成后选择“日本求职”，或输入：

```text
使用 $jp-shinsotsu-interview，进行无公司新卒一面模拟，30分钟，现在开始。
```

## 从仓库更新已安装版本

首次安装工具遇到已存在目录时会停止。更新时可以对 Codex 说：

```text
请从 hongyu0510/personal-skills 的 main 分支更新我本机已安装的日本求职 skill，源目录是 skills/jp-shinsotsu-interview。
先核对本地与仓库差异并备份本地版本，再更新这个 skill；发现本地独有修改时先说明差异。
```

本仓库的普通安装流程不会自动同步后续修改，需要在其他电脑上另行更新。

## 练习和维护

- 同一练习对话可以复盘后完整重练或按薄弱项训练。
- 复盘中单独列出有至少两次独立、可核对证据且确有规则修改必要的升级建议。
- 模拟练习对话不修改 skill 文件。将升级建议带到独立维护对话审查后更新，再将通过验证的规则同步到本仓库。
- 仓库保存通用规则和安装说明，不保存简历、职务经历书、面试答案或练习记录。
